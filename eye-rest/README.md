# 護眼提醒 · EYE REST（Android）

每隔一段固定時間，自動跳出全螢幕的休息畫面提醒你讓眼睛休息；休息時間到了會震動，接著自動開始下一輪計時。
介面走黑白搭配一點紅色的點陣風格（參考 Nothing Phone）。

## 功能

| | |
|---|---|
| 用眼間隔 | 1–180 分鐘，時間到跳出休息畫面（使用其他 app 時也會跳出，鎖定畫面時會亮起螢幕） |
| 休息時間 | 10 秒 – 30 分鐘，圓點倒數，結束時震動並自動關閉畫面 |
| 提醒文字 | 休息畫面上的標題與內文都可以在設定頁修改，並可預覽 |
| 震動 | 結束時震動（輕／標準／強）、跳出時輕震，靜音模式下也會震 |
| 勿擾時段 | 例如 23:00–07:00 不提醒，可以跨午夜，結束後自動恢復計時 |
| 休息統計 | 今天完成幾次休息、今天用眼多久、最近 7 天的點陣長條圖 |
| 通知欄開關 | 常駐通知顯示下次休息的倒數，可以直接按「關閉提醒」「重新計時」；從通知關掉後會留一則提示，按「開啟」就能恢復 |
| 快捷設定方塊 | 下拉選單裡的「護眼提醒」方塊，點一下開或關，副標顯示下次休息時間 |

流程是全自動的：用眼倒數 → 跳出休息畫面並開始倒數 → 休息結束震動 → 自動開始下一輪。
首頁另外有「重新計時」與「立即休息」兩個按鈕。

## 安裝

1. 用手機打開 <https://github.com/alittlecutesheep/time-log-app/releases/tag/eye-rest-latest>，下載 `eye-rest.apk`。
2. 點下載好的檔案安裝。第一次安裝時，Android 會要求允許瀏覽器（或檔案管理員）「安裝不明應用程式」。
3. 打開 app，允許通知。

每次 `eye-rest/` 有新的 commit，GitHub Actions 會自動重新打包並更新同一個下載連結。新版可以直接覆蓋安裝，設定與統計都會保留。

## 第一次使用要開的權限

到 app 的「設定 → 05 SYSTEM」，紅框標示的項目點「前往」：

- **顯示在其他應用程式上層**（最重要）：沒有這個權限，你在用其他 app 時休息畫面無法自己跳出來，只會出現一則通知。
- **通知**：通知欄倒數與開關，以及鎖定畫面時的全螢幕提醒都需要它。
- **全螢幕通知**（Android 14 以上）：螢幕關閉或鎖定時，讓休息畫面直接亮起來。
- **精確鬧鐘**（Android 12 以上）：讓提醒準時，一般會自動允許。
- **不受電池最佳化限制**：避免系統在背景把 app 關掉。小米、三星、OPPO 等品牌還可能有自己的「自動啟動」或「休眠應用程式」名單，記得把護眼提醒排除在外。
- **快捷設定方塊**：Android 13 以上可以直接按「加入」；較舊版本請下拉快捷設定 → 編輯 → 把「護眼提醒」拖進來。

## 運作方式

- 每個階段的結束時間都用精確鬧鐘（`setExactAndAllowWhileIdle`）喚醒，就算 app 被系統收掉也會準時觸發。
- 開啟提醒期間有一個前景服務常駐，負責通知欄的倒數與開關。
- 使用中且有「顯示在其他應用程式上層」權限 → 直接開啟休息畫面；鎖定或螢幕關閉 → 用全螢幕通知亮起螢幕。若某些品牌默默擋下了畫面，1.5 秒後會自動改用通知提醒。
- 休息畫面在獨立的 task 裡，結束後會回到你原本正在用的 app。
- 休息中按返回鍵不會關閉（沒有跳過按鈕）；按主畫面鍵離開的話，休息仍會照常倒數並在結束時震動。
- 重新開機後會自動恢復，並從頭開始一輪計時。

## 自己編譯

需要 JDK 17 與 Android SDK（compileSdk 35）。

```bash
cd eye-rest
./gradlew assembleRelease
# 輸出：app/build/outputs/apk/release/app-release.apk
```

或用 Android Studio 開啟 `eye-rest/` 資料夾。

### 關於簽章金鑰

`app/sideload.keystore` 直接放在 repo 裡，好讓每次 CI 打包的 APK 簽章都一樣，新版才能覆蓋安裝舊版。
因為 repo 是公開的，理論上別人也能用這把金鑰簽出可以覆蓋安裝的 APK，所以只從上面的 Releases 連結下載安裝就好。
如果之後想上架或更嚴謹，可以換成新的金鑰並改放在 GitHub Secrets。

## 技術細節

- 純 Android 框架 API（Java），沒有任何第三方函式庫；minSdk 26（Android 8.0），targetSdk 35。
- 介面全部用程式碼繪製：點陣字（5×7）、圓點進度環、點陣長條圖、開關與調整器都是自訂 View。
- 字型：Space Mono（SIL Open Font License 1.1，授權檔在 `app/src/main/assets/fonts/OFL.txt`）。
